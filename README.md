# Fraud Risk Engine

An end-to-end machine-learning project for estimating transaction fraud risk.

## Project goals

This project will demonstrate:

- reproducible data generation and validation;
- exploratory data analysis;
- fraud classification with imbalanced data;
- model evaluation and threshold selection;
- a FastAPI prediction service;
- PostgreSQL prediction logging;
- automated testing;
- Docker-based development;
- continuous integration with GitHub Actions.

## Project status

Currently under active development.

## Data

The project will use reproducible synthetic transaction data. It will not contain employer-owned, customer, or personally identifiable data.
